connect to github

Saving needs a token

The gallery writes straight to the repo through the GitHub API. There is no server and no public endpoint — the token stays in this browser and is sent only to api.github.com.

how to make one
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → this repo
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate, copy, paste above
Token saved locally in this browser only — revoke anytime on GitHub. Nothing is sent anywhere except api.github.com.
